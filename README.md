# dotNetRdf.Wrapping

Provides convenience functionality for mapping RDF to object-oriented code.

Built on [dotNetRDF](https://github.com/dotnetrdf/dotnetrdf) (`dotNetRdf.Core`).

## Installation

```
dotnet add package langsamu.dotNetRdf.Wrapping
```
